About half of the hidden regressions, at three tests a patch.

We ran the guard on 68 agent patches that pass SWE-bench but break other tests in the project’s full suite. It flagged a broken test in 35 of them. On patches that broke nothing, it flagged a median of 3 tests out of thousands.

Most of the other 33 go through calls a code graph cannot see: framework code that calls methods by name, operators such as ==, and tests that start the program in a separate process. Those need a record of which tests run which lines, a coverage map; that version is in progress.

Notes that notice when the code moves.

Some things an agent cannot learn from the code: why a function is shaped this way, the fix that was tried and reverted, the flag production depends on. Write them down next to the function they are about.

When that function changes, the guard hands the note to the agent and marks it as possibly out of date, until someone confirms it still holds.

$ codenib guard note add \
    "Cart copies its items, so callers can reuse their list." \
    --anchor shop/pricing.py:Cart.__init__ --kind invariant
After an edit to Cart.__init__codenib guard check

Notes on this code (1):

[invariant] Cart copies its items, so callers can reuse their list.

Notes that may be out of date (1):

[invariant] Cart copies its items, so callers can reuse their list.

.codenib/notes/cart-copies-its-items-so-callers.md; Cart.__init__ changed

After checking one, run `codenib guard note confirm <file>`.

Notes are Markdown files in .codenib/notes/, reviewed in pull requests like code.

Add it to your agent.

Two commands in your repository. The guard then runs each time Claude Code or Codex is about to finish, and hands back the tests its change reaches.

$ python -m pip install "codenib[graph]"
$ codenib guard install --agent claude
  • Use --agent codex or --agent all for Codex. Codex runs a new hook after you trust it in /hooks.
  • The first graph of a commit takes one to three minutes on a repository the size of Django or sympy; later sessions reuse it. Run codenib guard check any time to see the report yourself.
  • Requires Python 3.10+ and Git. Remove it with codenib guard uninstall.
  • The hook sends nothing anywhere. With --share-first-run it sends one anonymous event the first time it reports, so we can count installs that work.
