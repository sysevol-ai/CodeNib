# CodeNib Brand Assets

`codenib_icon.svg` and `codenib_logo.svg` are the canonical product assets.
The landing page and web application keep byte-for-byte mirrors generated by
`make branding-assets` and checked by `make branding-check`.

`codenib_wiki.png` is the release Quickstart screenshot generated from the
default static Wiki over a clean CodeNib checkout.

`readme/` holds the screenshots on the repository README, captured from the
hosted demo at a 1440×900 viewport (2× scale), downscaled to 1760 px wide and
reduced to a 256-color palette.

Update a canonical file, sync its mirrors, then run the check before committing.
