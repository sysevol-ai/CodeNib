# CodeNib 0.2.5rc1

This candidate rehearses the expanded 0.2.5 release on TestPyPI, including
Pyrefly, static entry paths and call-path checks. The original TestPyPI 0.2.5
artifacts remain unchanged. The [0.2.5 notes](0.2.5.md) describe the features.

`codenib[graph,mcp]==0.2.5rc1` identifies this rehearsal package. Public setup
continues to use the [verified stable release](../quickstart.md) until the
final 0.2.5 package is published and checked.
