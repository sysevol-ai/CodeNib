# Reference Deployments

Reproducible deployment profiles that connect CodeNib's repository compiler,
verified manifest, retrieval views, and agent-facing products on one system.
These profiles document a tested configuration; they are not hardware
requirements or universal performance presets.

## NVIDIA DGX Spark

Run a source-linked Wiki, CodeGraph, MCP clients, local embeddings, and local
generation from one verified repository index. The profile records exact
model/runtime revisions and separates repository loading, retrieval, and
generation measurements.

[Open the DGX Spark reference deployment](dgx-spark.md)
