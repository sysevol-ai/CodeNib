filesystem and `NoAccessHost`, with Node filesystem and subprocess imports

experiment does not promote it to a supported CodeNib backend.

Two worker contexts receive every selected file. The initialization API takes
text, so binary placeholders are hydrated through each provider filesystem's
own Buffer/write API **before** analysis starts. Both foreground and background
then attest the exact project directory listing and every original byte,
before and after the query batch. Neither can read the two tested host-only
paths through its filesystem. The wrapper provides no `require`, `process` or
`fetch` global. These are functional filesystem observations: **Node `vm` is
not a security sandbox**, and no arbitrary-JavaScript isolation claim follows.

The bootstrap first times out because its message adapter omits `onmessage`;

## Remaining semantics and product gate

The 43 definition-set differences are shared by both language-server forms;
observed examples include ranges that contain a type annotation or `**`, and
additional assignment targets. The three remaining reference differences
include a compiler range covering parentheses around `markdown`, two extra
field accesses in the language server, and an imported alias. In the alias
case, the compiler includes the later `profile_main(...)` call while both LSP
forms omit it. Do not classify every disagreement as a formatting difference
or silently rewrite ranges to improve the frozen totals.

This is one already exposed repository. It establishes no arbitrary package,
configuration, symlink, interpreter, platform or cross-language closure. Browser
Node has a 4,096 MiB **heap** limit and no CPU quota; the ordinary container has
two CPUs and a 4 GiB **process** limit. Their timing/resource boundaries differ,
so no speedup or memory advantage is asserted. The final browser RSS observation
is approximately 2.31 GB, not a product capacity guarantee.

The concrete existing consumer is the position form of MCP `lsp_definition`
and `lsp_references`. Today its preparation path still constructs the persisted
graph. Before any live route can serve it, implement and test authenticated
source-generation ownership, stale/post-edit publication rejection, bounded
provider shutdown and representative configuration/dependency behavior. Resolve
or explicitly scope the alias/reference contract before substituting results.
Keep the source-selection guard and evaluation-only provider boundary intact.
