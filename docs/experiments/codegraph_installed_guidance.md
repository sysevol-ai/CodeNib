## Installed runtime and source delivery

`5f9573d97f141e1588af30ea95b06ae988f104a1`. Its merged tree matches the reviewed
tree. The downloaded artifact ZIP digest matches GitHub's recorded digest;
all 485 packaged Python files match the merged source bytes. The exact wheel
and original ZIP are retained locally with their hashes in the
[control packet](codegraph_installed_guidance_2026_10_30.json).

An owned container installs that wheel offline over an existing prepared
dependency environment. It has two CPUs, 4 GiB memory, no network, a separate
product home and one active fixture bind. Other inherited source destinations
are masked. No host credentials, SDK home or Docker socket are mounted.
This verifies installed behavior, not a fresh dependency installation or its
time and cost.

From `/opt/admission`, outside both the analyzed fixture and any CodeNib
checkout, the probe imports the installed server, prompts and native owner
extension. All 485 Python hashes and the native-extension hash match the wheel.
The full twelve-tool surface and both one-tool exploration surfaces exactly
match the reviewed source producer, including descriptions, schemas and
instructions, under MCP 2.3.0.

The probe indexes two original fixture files with BM25 and connects through
real stdio to the installed server in deferred graph mode. A query alone
returns verified source with dependency expansion disabled, including the
complete five-line `calculate_total` definition at `billing.py:1–5`. The
772-character instructions arrive intact, and both fixture source hashes
remain unchanged. This uses no provider or model and records no voluntary use.
