# TypeScript schema-v5 fixture

The TypeScript and TSX source files and decoded SCIP text are reduced from
output generated by `scip-typescript 0.4.0`. The document order is intentionally
changed so imports are decoded before their target definitions, exercising
definition promotion.

`MissingType` is the only synthetic occurrence. It models a project-package
symbol whose defining document is unavailable, so the graph contract can test
an explicit reference-only vertex. Tests inject an explicit `kind` field into a
copy of the fixture to exercise future-provider precedence; the checked-in
0.4.0 output itself contains no `kind` or `Import` role fields.
